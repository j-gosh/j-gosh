## Hi, I'm Justin 👋

I'm a mobile developer based in Harrisburg, PA. I build cross-platform apps in Flutter and React Native, and I'm comfortable working in native iOS and Android code or on the backend when a project calls for it.

Much of my recent work has been on apps that talk to hardware or handle sensitive data: Bluetooth and USB devices, health monitors, and regulated products in defense, fintech, health tech, and IoT. I run [The Big 3 LLC](https://www.thebig3llc.com/), a small mobile consultancy, and take on contract work.

### What I work with

- **Cross-platform:** Flutter / Dart, React Native / TypeScript
- **Native:** Kotlin, Java, Swift, JNI, Dart FFI, method channels, home screen widgets
- **Backend & cloud:** REST and WebSocket APIs, AWS (Cognito, Amplify), Firebase, Supabase, SQL / NoSQL, C# / .NET
- **Shipping:** App Store Connect, Google Play Console, TestFlight, GitHub Actions CI/CD, automated testing, design systems with Widgetbook

### Recently shipped

- **Ventos** ([App Store](https://apps.apple.com/us/app/ventos/id6743567127) · [Google Play](https://play.google.com/store/apps/details?id=com.ventos&hl=en_US)): Flutter app for a Bluetooth gut-health monitor. I joined as one of two core mobile developers and we took it from an unstable codebase to launch on both stores in about a month. Along the way we grew the test suite from 1 test to 160 and traced slow API cold starts (4-7s) to the database connection pool, bringing typical loads down to 1.1-1.5s.
- **Weapon sight configuration app (defense):** Android app for configuring a close quarters sight over Bluetooth and USB, built with a team of electrical, mechanical, and firmware engineers. Includes JNI bindings to an embedded C++ ballistics library for live calculations.
- **One-Tank Pulse Monitor:** ([App Store](https://apps.apple.com/us/app/one-tank-pulse-monitor/id6761924171) · [Google Play](https://play.google.com/store/apps/details?id=com.lpg_tank_solutions.one_tank&hl=en_US)) Migrated separate native Java and Swift apps into a single Flutter app for remote propane tank monitoring, now used by 100s of their customers on both stores.
- **Fintech education app:** Converted a Kotlin MVP into a Flutter app that teaches investing through real-time stock trading over WebSockets, with COPPA- and FERPA-compliant auth and storage.
